# d185ceed5cc1

Rows contain independently placed color-8 walls and ordered colored pebbles on a zero background. The canonical rule treats every maximal run of non-wall cells—including leading and trailing edge runs—as an independent segment. Within each segment, nonzero pebbles preserve their left-to-right order while packing against the segment’s right edge; walls stay fixed.

The selected v3.0.0 sampler emits 4–6 by 10–13 grids, uses the full ARC palette 0–9, varies wall positions independently by row, and deliberately includes examples that refute whole-row compaction, color sorting, and “only segments bounded by two walls” shortcuts.

Kind: `per_puzzle`. Selected version: `3.0.0`. Rule hash: `a1ebff603893`.
