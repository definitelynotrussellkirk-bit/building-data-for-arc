## Packet preflight compatibility

`preflight_compat.py` is a narrow launcher for this packet revision.  The
immutable canonical record stores `test` as one pair object, while the bundled
base preflight iterates it as a list.  The launcher treats that singleton as a
one-item sequence in memory and delegates source binding, drift checks, native
parametric execution, and receipt writing to the bundled preflight unchanged.
It does not modify catalog data and does not grant owner acceptance.
