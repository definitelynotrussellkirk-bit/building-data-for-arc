# Color-keyed component settling

Design: discover full-width destination bands by their uniform interior and equal
left/right marker columns. Split the staging area's objects into same-color
four-connected components. Match each component color to a band, recolor by its
edge marker, and translate to the measured band floor (canonical) or ceiling
(alternative), preserving columns and shape. Erase the staging objects.

Implementation checklist: test literal translations and every original label;
author independent Racket; build standalone sampler and matched-input adapter;
test strict controls, counts, four novel queries and public masking; audit finite
rivals including whole-color and eight-connected shortcuts; run source-bound
preflight, wrong-destination causal replay and relocation; package owner-pending.

Scope: no edits to shared authority, parent, catalog, original gold or acceptance.
The alternative changes settling direction, not input generation. Minimum two
teaching examples, six maximum, four independently requested queries; source
order is private and controller presentation shuffles the full bank first.

Current result: 38 copied-runtime tests pass; all four original labels and all
preflight generated labels match protected Racket. The 32-seed / 320-lesson audit
eliminates all twelve declared rivals. A global-floor counterfactual changes ten
cells. Six generator-only relocated labels and sixteen public one-query views
pass. These are reviewer authoring checks, not owner registration or acceptance.
Grammar is explicit: unique band interior colors, four-connected source shapes,
no source edge-column occupancy, no destination collisions, and shapes no taller
than their matching band. Noncanonical input validation fails closed. The random
palette, band order/height and reflected shapes vary independently of setting.

Additional source-bound execution checks: 84 labels pass, covering maximum
six-demo/four-query requests, the maximum supported seed, all base difficulty
bands, alternative-setting originals and each of the twelve retained rival
counterexamples. The original-alternative labels are claims, not official gold.
