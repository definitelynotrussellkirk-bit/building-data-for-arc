# `138ffc14ac65` native parametric family

Parameter: `finish_rule`

- `up_only` — exact canonical/default program: each seed projects its color upward to the top edge.
- `equal_top_bridge` — perform the canonical projection, then bridge each color that appears exactly twice among the newly derived top-edge endpoints.

The generator authors equal-color seed pairs in disjoint column bands plus singleton distractors. No input seed lies on the top edge. Therefore the alternate's second operation reads an input-dependent intermediate produced by the first operation; running it on the raw input has no top endpoints to bridge.

The demo and query streams are independent and prefix-stable. Episodes support 2–6 demonstrations and 1–4 queries. The fourth query is a substantive 30×30 case with four independent relay pairs.
