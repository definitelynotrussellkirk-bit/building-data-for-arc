Canonical-scale square input (2×2 through 5×5). Every third sample uses the exact public size/palette profile—2×2/3 colors, 3×3/4 colors, 4×4/5 colors, or 5×5/8 colors—and the intervening samples use one fewer or one more visible color. This preserves the task's scale while refuting a learner that recognizes only the public profiles. Every color is visible, the arrangement varies in both axes, and transpose-symmetric teaching aliases are rejected. The rule replaces each input cell with a solid 2×2 block of the same color, producing a 2h×2w output.
