## What is delivered

Each home contains a fresh standalone base generator, commented Racket reference,
native adapter and promotion contract, byte-identical canonical and kernel copies,
focused tests, current notes and source-bound preflight inventory. Geometry,
colors, object counts and input-dependent intermediate values vary with seed.

the query bank. Both families include substantive 30x30 cases.

The reusable `workspace/authoring_preview.py` exports and verifies unregistered
public-creation evidence without pretending that it is native qualification.
It freezes the complete four-query permutation privately, hashes each public
file from only its visible bytes, and checks live source/evidence closure,
answer/future-query invariance, missing files, byte/hash changes and private
mapping tampering. Each home has an identical standalone copy and focused tests.
