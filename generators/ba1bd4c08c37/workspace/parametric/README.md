# `ba1bd4c08c37` output-corner parametric prototype

This directory is an **isolated prototype**. It does not change the selected
canonical authority or add a production generator axis.

The episode-level parameter is `output_corner`:

- `top_left` — canonical/default; its Racket source is returned byte-for-byte
  from the canonical ledger.
- `top_right`
- `bottom_left`
- `bottom_right`

One setting is selected deterministically **once per six-pair episode**. Inputs
come from the selected production generator and retain its doubly symmetric
foreground box. A bounded deterministic search rejects a seed quadrant when any
two raw corner crops coincide, so every retained pair distinguishes all four
settings. The public challenge contains five labelled demonstrations and one
unlabelled query; it omits the seed, setting, program, and query answer.

`python_reference` is only a test/debug mirror. Retained labels are generated by
executing each materialized Racket rule through the bundled bridge.

From `WORK/repo`, build immutable evidence with a fresh destination:

```bash
python3 ../../review.py run python3 \
  generators/ba1bd4c08c37/workspace/parametric/build_prototype.py \
  --out-dir ../checks/parametric/output-corner-v1
```

The output includes public challenges, private Racket evidence, one same-input
four-setting witness, exact rule files, hashes, a manifest, and `summary.json`.
