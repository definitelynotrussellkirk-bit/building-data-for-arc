## `component_contract_probe.py`

A fast, Racket-free preflight for future edits. It independently reconstructs same-color 4-connected components, verifies the border-touching output law, checks every declared teaching rival on deterministic draws, and scans every cyclic lesson start in a bounded schedule.

From the repository root:

```bash
python3 generators/7f31c4f794b2/workspace/component_contract_probe.py \
  --draws-per-band 100 --schedule-period 100 \
  --out ../checks/component-contract-probe.json
```

A pass is an iteration aid, not a substitute for the source-bound Racket battery or `arcpuzzles lesson-census`.
