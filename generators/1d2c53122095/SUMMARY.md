A zero-background grid contains two to five strictly nested yellow (4) rectangular frames and k red (2) markers in the top row. Count the red markers, select the k-th frame from outside to inside, and fill cyan (8) background inside that frame down to the next inner frame. If k selects the innermost frame, fill its central interior. Linked profiles vary canvas size, frame count, frame gap, aspect ratio, placement, and depth.

Kind: `per_puzzle`. Imported version: `3.1.0`.

The ordinary sampler uses a six-profile cycle per difficulty with four demonstrations. Every cyclic four-demo window covers outer, intermediate, and innermost behavior, and the following query uses a profile absent from those demonstrations.
