Dense canonical 4x6 lattice of 3x3 symbol tiles separated by zero gaps. The
unique color-8 tile defines an exact occupancy mask shared by 3–6 key tiles.
All matching keys become 8; nonzero cells in non-key tiles between aligned
keys become 7. Production lessons cycle horizontal, vertical, and mixed bridge
layouts and always include a same-row-totals/different-mask distractor so the
canonical-fitting row-sum shortcut is explicitly refuted.

Kind: `per_puzzle`. Reviewed version: `4.0.0`.
Approval is derived by the catalog from current code and retained evidence.
