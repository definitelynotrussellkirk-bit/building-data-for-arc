# Parametric diagonal-ray prototype

`extent=edge|two_steps` is fixed for an episode. `edge` is the exact canonical
Racket authority; `two_steps` keeps the same body/tail inference but limits each
ray to two new cells. The sampler is setting-independent, constructs every pair
with more than two legal continuation cells, supports 2–6 demonstrations and
1–4 prefix-stable queries, and ends with a substantive 30×30 four-ray query.

`promotion.json` is a proposal inventory only. Qualification must execute all
private labels and the demonstration-only finite-survivor check through the
protected Racket worker. Public challenges contain only demonstrations and the
currently revealed query; settings, programs, answers and future queries remain
private.
