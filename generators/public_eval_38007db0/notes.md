# Public parent 38007db0 — row-wise outlier extraction

The input is a complete separator lattice. Within every tile row, exactly one complete tile differs from the otherwise repeated tile. The canonical transformation keeps that sole outlier from each row and stacks the selected tiles vertically in original row order, preserving the outer vertical separator strips and every horizontal separator band. The general Racket rule discovers separator runs, parses variable tile sizes and one- or two-cell separator thicknesses, compares complete tile patterns rather than color counts, and validates the one-outlier grammar before rendering.

All four supplied labelled pairs were checked privately: two official demonstrations and both official test solutions. `reference.rkt`, `workspace/parametric/canonical.rkt`, and the Python mirror agree exactly on those labels. Gold labels are used only by author-private tests and preflight; neither the generator nor the parametric family reads the solution file.

The episode-fixed family has two settings on matched inputs. `stack_order=source_rows` is the exact canonical default. `stack_order=difference_desc` first identifies each row’s unique and repeated tiles, computes their cellwise Hamming distance, then stably stacks the selected outliers by decreasing distance. This is a genuine A→intermediate→B rule: the ranking key does not exist until both tile roles have been inferred and compared. The retained counterfactual instead ranks by the selected tile’s foreground count; generated scenes deliberately make that ordering disagree with Hamming-distance ordering.

The authored support is 2–6 demonstrations and four independently presented, prefix-stable private queries. Fresh scenes vary row/column counts, tile geometry, palettes, outlier columns, masks, add/remove differences, and separator thickness. The final query is exactly 30×30. Every scene separates source order, reverse order, difference order, foreground order, outlier-column order, majority-tile selection, and fixed first/last-tile shortcuts within the finite declared rival bank. Presentation order is independently shuffled; public views reveal one query input with no setting, program, answer, future-query, source-index, seed, or total-query hint.

The grammar intentionally requires a complete outer separator frame, uniform rectangular tile bands, at least two tile rows and three tile columns, and exactly one tile pattern with multiplicity one versus one pattern with multiplicity `columns-1` in each row. Arbitrary damaged lattices, mixed tile dimensions, or rows with multiple distinct outliers are outside this family.
