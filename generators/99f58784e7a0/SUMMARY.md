Full color-8 wall rows and columns partition a color-0 background grid into two to four rectangular chambers. Each chamber contains exactly one nonzero, non-8 seed cell. The rule preserves the walls and fills every cell in each chamber with that chamber's seed color.

The version 3 curriculum covers four canonical wall morphologies (`vertical_unequal`, `vertical_equal`, `horizontal_three`, and `grid_2x2`) at canonical and expanded scales. It alternates globally distinct and deliberately reused chamber colors so that a three-example lesson refutes the plausible but wrong shortcut “fill only when every chamber color is globally unique.”
