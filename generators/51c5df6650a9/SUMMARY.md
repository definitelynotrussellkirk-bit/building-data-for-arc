# 51c5df6650a9 — Legend-Ordered Pack

A same-sized black grid uses its first row as an ordered color legend and keeps row 1 blank. Rows 2+ contain one separated component for each legend color. The rule tightly crops those components and packs them left-to-right from output row 1, with one blank column between crops, in legend order rather than body scan order.

Version `3.0.0` exposes three exact observable controls: one of five canonical height/width profiles, 2–4 legend colors, and a contiguous, shifted, or canonical legend layout. Ordinary draws use contiguous or shifted layouts and a deranged body order so both the fixed-columns canonical shortcut and body-scan-order rival are directly refuted.
