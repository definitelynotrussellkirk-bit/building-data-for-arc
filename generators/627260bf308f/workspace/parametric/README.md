# `627260bf308f` native rank-relay family

The default `finish_mode=rank_only` returns the selected canonical Racket source
byte-for-byte: sort placeholder-8 components by occupied size and recolor them
in the left-to-right row-0 palette order.

The alternative `finish_mode=rank_relay` adds a causal remote-payload stage.
After the canonical recoloring, a singleton color-9 selector casts right to the
first recolored component. Its newly assigned palette color selects the matching
bottom-row swatch, and that swatch's reserved vertical corridor is painted 9.
Skipping the rank stage leaves the hit color at 8, for which no swatch exists.

Inputs are matched across settings. The adapter supports 2–6 demonstrations and
1–4 queries with count-independent prefixes. Query four is a 30×30 scene with
five irregular distinct-size components, a selector, shuffled palette swatches,
and a full-height remote payload corridor.
