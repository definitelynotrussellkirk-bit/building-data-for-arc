# Review tools

Run tools through the packet's public review wrapper so imports and Racket authority resolve in that packet's own runtime.

- `probe_semantics.py --out NEW_DIRECTORY --baseline PATH_TO_ORIGINAL_GENERATOR`: obtain Racket labels in bounded batches and verify manual/canonical examples, validators, actual declared rivals, witness claims, baseline support and a deliberately shorter lesson.
- `probe_independent_rivals.py --cases RETAINED_CASES_JSON --census RETAINED_CENSUS_JSON --out NEW_FILE`: independently rescore cross-wall, global-row-barrier, rigid-run and adaptive-sort alternatives; the optional census produces every adaptive-sort error vector. No new reference labeling.
- `implementation-plan.md`: decisions and measured revisions.

All output paths must be new. Large census evidence in the return is losslessly compressed; use checks/COMPRESSION.json and checks/RESTORE-EVIDENCE.md before rerunning a command that reads an original JSON path.
