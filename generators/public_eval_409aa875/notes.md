Canonical rule: every isolated three-cell object is an oriented pointer.  Chevron tips project cardinally and L elbows project diagonally, always five cells.  Empty endpoints become 9, shared endpoints become 1, and an endpoint landing on another pointer recolours that whole pointer 9.
