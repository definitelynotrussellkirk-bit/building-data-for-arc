# Task-local review tools

Start with `HANDOFF.md` for exact runtime staging, task tests, concentration,
real-authority comparison, audit reproduction, and fixture-repair commands.

- `review_probe.py`: source-bound portable staging, diversity/recurrence census,
  opt-in task-local support gate, and actual Racket parity.
- `fixed_bank_capacity.py`: exhaustive support of the retained fixed bank.
- `audit_findings.py`: concrete findings for the two assigned audit targets.
- `verify_fixture_repair.py`: reproduce the shared solve-fixture import failure
  and test its proposed repair in isolation, without changing shared source.

Scripts retain evidence and do not change training approval. Runtime directories
are working copies, not returned artifacts. The separate example-based solver
and public ambiguity probe are in the return's `solve/` directory.
