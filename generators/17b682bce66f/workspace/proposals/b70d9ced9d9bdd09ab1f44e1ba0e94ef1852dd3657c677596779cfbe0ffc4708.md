## What the semantic contract actually checks

The competitor set contains all 24 assignments of quarter-turn values
`0,1,2,3` to anchor colors `2,3,4,5`, crossed with five explicit
collision/order policies:

- row-major max merge;
- reverse-order max merge;
- protected-anchor max merge;
- anchors-first max merge; and
- row-major overwrite.

The intended rotation assignment combined with intended row-major max merging
is excluded, leaving **119 competitors**. `lesson_identifiable(demos, query)`
reports any declared competitor that fits every demonstration yet changes the
query answer. `_contrastive_grid` uses deterministic rejection sampling to
construct a scene whose intended output differs from all 119 rivals.

`SEMANTIC_WITNESSES`, `WITNESS_RIVALS`, `LESSON_COMPETITORS`, and
`EXAMPLES_NEEDED = 3` expose this contract to the shared semantic gate. The
reusable `workspace/lesson_probe.py` measures the same finite class without
private labels and records target/scorer source hashes, seed ranges, survivors,
and per-band results.
