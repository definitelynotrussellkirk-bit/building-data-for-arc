# Portable border-contact chain

Runtime closure: `adapter.py`, `engine.py`, `canonical.rkt`.
`build_generator.py --check` detects ordinary-generator drift.
After protected public preflight, use `verify.py --preflight PATH --out NEW --seeds 64`
and `replay_color_shortcut.py --preflight PATH --out NEW_JSON` through `review.py run`.
The first audits setting-specific rivals, request boundaries, public exports,
source identity and causal labels; the second replays the retained color-order
failure and corrected lesson. Neither changes owner approval or registration.
The shared `arcpuzzles.review_witness check --public-preflight ...` is the
owner-compatible causal replay path. See ../../notes.md for interpretation limits.
