# Native family: gravity then landed-cluster selection

`gravity_only` is the exact canonical authority. `mark_largest_landed_cluster`
first performs canonical per-column gravity inside each color-5 frame, then
recomputes the color-2 components created by landing and recolors the unique
largest one color 9. Every generated scene contains a source/post-gravity rank
inversion, so selecting before gravity is observably wrong.
