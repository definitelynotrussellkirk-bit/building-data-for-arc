# 09d287bbfa0b

Four-fold reflection across a full non-7 cross. The first full non-7 row and
column are the axes; every off-axis non-7 cell is read from the original input
in row-major order and paints each in-bounds reflected cell independently.
Later source cells overwrite earlier source/reflection values. Off-color cells
embedded in an axis are not sources.

Version `3.0.0` alternates exact canonical shape/palette anchors with a mixed
teaching witness. Each mixed input combines a multi-quadrant same-orbit
collision, an off-color axis cell, and partial clipping. Therefore every
three-demonstration production lesson and every 3-of-4 query rotation contains
a demonstration that refutes all four declared plausible rivals. Exact
controls remain available for grid height/width, separator, source count, and
all five textures over the full declared domains.
