# Parametric object-transform prototype

`transform=transpose|rotate_cw` is private and fixed for the full episode.
`transpose` is the exact selected canonical Racket authority. Both settings use
identical input scenes, preserve left-to-right object ordering and vertical
packing, and differ only in the geometric operation applied to each crop.
Every object is constructive evidence against the rival transform.

The adapter supports 2–6 demonstrations and 1–4 prefix-stable queries. The
fourth query is a 30×30 scene with five asymmetric objects distributed across
both axes; transformed output remains within ARC bounds. Qualification must use
the protected Racket worker. Settings, programs, answers and future queries are
private controller metadata, never public challenge bytes.
