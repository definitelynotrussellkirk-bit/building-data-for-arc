# Parametric family: 758360aea29b

This finite family preserves the exact canonical `pairwise_width` program as
the default and adds `pivot_distance`.

`pivot_distance` is deliberately sequential: **A** selects the unique tallest
rectangle and records its bounding-box width; the intermediate is that pivot
width; **B** replaces each object's raw width by its absolute distance from the
pivot and emits the same 1/2/3 comparison matrix over those scores. Removing or
changing A changes B's output on every constructive lesson profile.

The sampler is setting-independent, count-prefix independent, produces 2–6
constructive demonstrations and 1–4 queries, and includes a 30×30 stress input.
`promotion.json` is only an authoring proposal; owner qualification/acceptance
and training admission remain separate.
