- proof that the 3-seed-Manhattan/4-seed-Euclidean rival fits all four canonical training demonstrations;
- the exact generated input at `difficulty=easy, seed=1, sample_index=3`;
- the intended and rival outputs;
- all differing cells; and
- direct parity of the intended output with the executable Racket authority.
