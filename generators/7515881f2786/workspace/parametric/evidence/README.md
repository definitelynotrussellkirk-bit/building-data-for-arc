# Parametric evidence

`current/self_audit.json` is the bounded source-local audit for the native
`bridge_axes` family. `manifest.json` is regenerated from final source and
current evidence before native qualification. Retained `materialized/` and
`returned/` files describe earlier prototype runs and are historical only.

Public projections contain demonstrations plus one query input and exclude
settings, programs, answers, future queries and total-count hints. The evidence
is reviewer-produced and finite; owner acceptance and training admission remain
pending.
