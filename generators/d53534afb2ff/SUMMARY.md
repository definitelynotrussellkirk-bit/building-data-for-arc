# d53534afb2ff

One or two exact hollow rectangular frames contain connected objects. Every
strictly enclosed object inherits its enclosing frame's color; objects outside
all frames remain unchanged.

The selected generator uses a four-example teaching schedule covering:
1. two singleton targets,
2. an unchanged outside object sharing a target color,
3. a connected multi-cell target, and
4. multiple non-color-3 targets inside one frame.

Frame and object role colors are sampled deterministically from the ARC palette
for every example rather than fixed by profile. This prevents profile/canvas
shape from serving as a memorized color-map shortcut.

Kind: `per_puzzle`. Selected version: `2.0.0`. Canonical rule hash:
`372b08419c67`.
