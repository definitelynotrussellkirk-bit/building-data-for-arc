# Native transform-source family

`explicit_key` is the exact selected canonical program. `first_component_size`
keeps legend-order component extraction and gallery packing, but identifies the
first legend component, measures its occupied size, maps sizes 3/4/5 to transform
keys 2/3/4, and applies that derived key to every crop.

The sampler is deterministic and setting-neutral, supports 2–6 demonstrations
and 1–4 prefix-stable queries, and reserves a distributed 30×30 scene as query
four. `last-component-size-counterfactual.rkt` is the wrong-intermediate foil.
