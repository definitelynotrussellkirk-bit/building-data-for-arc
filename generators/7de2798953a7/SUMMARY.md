Rows contain two equal nonzero endpoints separated by an all-zero gap. The
reference rule copies that endpoint colour into interior offsets 1, 3, 5, ...
from the left endpoint. Unequal-colour endpoint rows are lawful distractors and
remain unchanged.

The selected generator keeps all ordinary defaults on one of the four exact
canonical height/width/palette profiles. A three-slot schedule emits a canonical
scene followed by two contrast scenes, so every ordinary three-demonstration
lesson surviving one query holdout includes the equality witness. Every scene
also contains an odd endpoint span to identify the left-anchored phase. Easy,
medium, and hard preserve the same profile support while using compact, varied,
and widest legal spans respectively.
