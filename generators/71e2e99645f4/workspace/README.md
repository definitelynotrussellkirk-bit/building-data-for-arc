# Workspace

Task-local drafts and reproducible probes live here. The selected implementation
is `../generator.py`; workspace artifacts are never automatically selected.

- `probe_contract_repair.py` reproduces the earlier geometry and override repair.
- `probe_position_shortcut.py` derives the strongest canonical position lookup,
  checks its exact held-out disagreement, and audits ordinary draws plus every
  three-of-four lesson rotation.
- `parametric/` contains the separate proposed section-order/class-palette rule
  prototype and its runnable evidence command.
