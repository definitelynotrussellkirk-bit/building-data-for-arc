# Midpoint-key relay family

The exact canonical default remains unchanged. The alternate first computes the
midpoint of the first two row-major nonzero endpoints, reads the color of the
key cell aligned below that midpoint, and uses that input-derived color to
select a remote payload to recolor cyan. Inputs are identical across settings.

The fourth query is a substantive 30x30 case. The retained protected-Racket
counterfactual skips midpoint extraction and always reads the grid-center key.
