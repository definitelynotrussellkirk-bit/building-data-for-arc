# Workspace

The complete task-local parametric family is in `parametric/`. It preserves the exact canonical default and adds the sequential `first_hit_payload` setting.

Use `parametric/adversarial_probe.py` for a bounded sampler/lesson/certificate audit. The native adapter and promotion contract are `parametric/adapter.py` and `parametric/promotion.json`; exact-source evidence and its manifest are under `parametric/evidence/`.

Workspace source is reviewer-ready only. Owner source review, native qualification, acceptance replay, and any later training admission remain separate gates.
