# Workspace

Keep alternate drafts, reproducers, and unfinished experiments here.
The selected implementation is `../generator.py`. Workspace drafts are never automatically selected.

## Retained probes

- `lawful_minimal_probe.py` executes the current canonical Racket program and
  selected `self_check` on exact singleton, short-line, and solid-2x2 inputs.
  It is source-bound evidence for interpreting generic defect-lint warnings,
  not a waiver or production dependency.
- `parametric/output_orientation.py` is an isolated episode-level horizontal /
  vertical output-orientation prototype; it is not selected production code.
