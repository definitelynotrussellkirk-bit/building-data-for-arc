# Independent rectangle-cross curricula

The native contract retains `join_axis=none|horizontal|vertical` and adds
`cross_area_cascade`. The three old program strings are byte-exact. The original
join sampler is preserved in `join_adapter.py`; the independently returned
cascade sampler/rival curriculum remains unchanged in `native.py` and `rivals.py`.
Read `JOIN-README.md` and `CASCADE-README.md` for their original detailed scopes.

This is a disjoint episode-level union. Horizontal/vertical rules draw the join
curriculum; cascade draws the cascade curriculum. The shared canonical default
keeps the current join curriculum unchanged. The incoming canonical program is
byte-identical and deduplicated; its independently authored canonical sampler
and evidence remain available in `native.py`.
Each original sampler keeps its own setting-neutral inputs, stable prefixes and
2–6 demonstration /1–4 query limits. Input matching holds within each source
curriculum, rather than across independent curricula. No Cartesian interaction
between joining and cascading is introduced.

The cascade program is totalized by a visible input-grammar guard: it requires
one uniquely largest eligible odd rectangle and exactly one distinct eligible
rectangle whose area equals its cross occupancy. Outside that original admitted
grammar it returns the input unchanged. On original cascade inputs it executes
the exact authored body, including counting actual `after-a` cells. This avoids
an accidental second valid interpretation on the original two-demo join lesson;
branch identity alone is never accepted as evidence of parameter learnability.
The native worker must fit all four executed programs to demonstrations alone.

All query answers, branch/settings and programs remain private. `public_turn`
projects one query without future inputs, an index or a total-count hint.
Original production generator, canonical authority and approval are unchanged.
Fresh native qualification/acceptance of this union is required before use.
