A zero-background grid contains two or three distinct nonzero colors. For each
color, exactly three cells occupy three corners of one axis-aligned rectangle
and the fourth corner is blank. Complete every rectangle by painting only its
missing corner with the same color.

Kind: `per_puzzle`. Current generator version: `3.1.0`.

The default lesson schedule alternates fixed- and mixed-orientation puzzles so
three demonstrations still distinguish per-color completion when any one of
four consecutive labelled pairs is used as the query. Approval is derived by
the catalog from current code and retained evidence.
