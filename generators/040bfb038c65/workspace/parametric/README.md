# Parametric family: 040bfb038c65

This native adapter keeps the exact canonical `outsider` program as its default.
The alternate `farthest_partner` setting first identifies the singleton D4 shape
class, then uses that object's input-dependent corner anchor to select the
farthest repeated-shape object for recoloring. Inputs are matched across settings.

Supported episodes use 2–6 demonstrations and exactly four controller-side
queries. The fourth query is a 30×30 boundary-spanning stress case. Public bytes
must be produced with `reviewer_support.public_challenge_bytes`; private settings,
programs, query answers, and future queries are not part of the first model turn.

From the packet root:

```sh
python3 review.py run python3 -m pytest -q generators/040bfb038c65/tests/test_parametric_adapter.py
python3 review.py run python3 generators/040bfb038c65/workspace/parametric/audit.py \
  --out generators/040bfb038c65/workspace/parametric/evidence/current/teaching-audit.json
python3 review.py run python3 -m arcpuzzles parametric qualify 040bfb038c65 \
  --out ../checks/040bfb038c65/qualification --summary
```

The audit is finite: it checks declared rivals and sampled seeds, not every
possible human hypothesis. Native qualification and owner acceptance remain the
authority for usable episodes.
