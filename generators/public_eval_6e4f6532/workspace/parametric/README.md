# Guide-directed keyed object relocation

This native family preserves public parent `6e4f6532` as the canonical
`toward` setting. Two-cell coloured guide strips partition the scene. Azure
objects contain maroon key cells and coloured side tabs; detached maroon keys
are destinations. First pair each object with the key having the same anchor
shape/cardinality and infer the D4 transform from the guide-tab colours. Then
erase the source and stamp the transformed whole object over the destination.

`orientation_mode` is fixed for an episode. In `toward`, each tab faces the
matching coloured guide line; in `away`, it faces the opposite direction. The
same generated inputs are valid for both settings. Symmetric one- and two-cell
anchors deliberately make the guide colours necessary to determine orientation.
The first two demonstrations vary palettes, target geometry and D4 branches.

The constructor provides six demonstrations and four independently shuffled
queries, including a substantive 30x30 scene. It admits 2..6 demonstrations and
1..4 query prefixes. This is a finite constructive family: it covers four-sided
outer guide frames, two movable objects with unique key cardinalities, all D4
transforms, and collision-free source/destination placements; it does not claim
all possible line networks or ambiguous repeated-key assignments.
