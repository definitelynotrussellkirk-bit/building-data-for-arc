# Run-length pulse superposition

Private episode parameter: `pulse_phase=leading|trailing`. First value is the exact newly authored
parent reference. Support: 2–6 demos and 1–4 requested source queries. Generate
four queries for training; the public helper shuffles that full bank before any
early stop. Inputs are matched across settings. All labels from `generate` are
Python claims until the protected reference runtime verifies them.

`adapter.py` is self-contained apart from its exact adjacent `canonical.rkt`.
`generator.py` reuses the adjacent adapter in both the source checkout and the
owner's `puzzle_generators/per_puzzle/TASK/` layout. No official example data or
answers are loaded by either generator or adapter.

```sh
python3 review.py run python3 ../checks/verify_relocation.py --out ../checks/new-relocation.json
```

Use fresh evidence paths. The audit tool validates source hashes, all supported
count prefixes, both settings, finite rivals, typed grids, Racket parity,
source-bound causal programs, and shuffled single-query exports. Its companion
`checks/test_audit_public_family.py` rejects hidden public fields, boolean/noninteger
cells, duplicate outputs, tampering, and stale source bindings.

Only one `audit-current/exports/public/<sha256>.json` is a model-visible turn.
The directory listing, manifest, private permutation, programs, settings, other
queries, and labels are controller-only. `public_turns(seed, settings, demos,
presentation_seed=0, count=1)` produces the same first turn as `count=4`.
