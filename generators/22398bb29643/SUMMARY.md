Three to six separated monochrome polyominoes, each with 3–5 cells, are
summarized as one row of component colors ordered by bounding-box top row and
then left column. Canonical-scale profiles alternate with repeated-color
witnesses, so a rule that emits each color only once is not a valid shortcut.

Kind: `per_puzzle`. Current version: `3.0.0`.
Approval is derived by the catalog from current code and retained evidence.
