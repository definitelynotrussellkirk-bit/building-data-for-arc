# c3052979ff96 native parametric relay

The family exposes one private episode-fixed setting:

- `rotation_only` — exact canonical selected Racket bytes.
- `relay_hit_color` — compute the rotated source footprint, read the unique
  color-5/6/7 cue orthogonally adjacent to that footprint, stamp the footprint red, then
  recolor both that cue and its same-colored separate payload red.

The two settings receive byte-identical inputs for the same seed and counts.
Two through six demonstrations are supported; every episode contains four
queries covering controls 1, 2, 3, and 4. The first two demonstrations both use
the canonical identity control 1 and the same source quadrant but different cue
colors, so the historical code-1-as-clockwise shortcut, code-only, source-location-only, fixed
color, largest-payload, all-payload and first-target-cell shortcuts fail from
visible demonstrations alone. The final query is a substantive 30×30 boundary
case.

`adapter.certificate()` is a finite-rival teaching audit, not a uniqueness
proof. Native qualification independently re-executes every claim through the
protected Racket worker.
