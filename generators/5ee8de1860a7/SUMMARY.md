Create a 3..15 by 3..15 zero-background grid containing exactly one nonzero
marker in the interior. The output keeps the input dimensions, paints the
complete outer border in the marker color, and leaves the output interior zero.

Thirty percent of default sample indices reproduce one of the five strict
canonical centered-marker profiles. Every other default draw follows a
rotation-safe deterministic cycle: dimensions and colors do not collide within
an adjacent four-sample window and the marker is off-center. Consequently, each
of the four possible query rotations leaves three demonstrations that rebut the
documented fixed-size, fixed-color, and center-only competitors. Exact user
overrides remain independent; impossible dimension/marker pairs are declared in
`INCOMPATIBLE_OVERRIDE_COMBINATIONS`.
