# Framed palette matching

`match_mode=contains_all` is the byte-identical canonical reference. The two
alternatives erase panels with any key-color overlap or exactly the key palette.
Generate 2..6 demonstrations (minimum two) and 1..4 queries; authoring evidence
uses a complete four-query bank. All input streams match across settings.

The standalone native folder contains `adapter.py`, `kernel.py`, `canonical.rkt`
and `promotion.json`. `kernel.py` is a byte-identical copy of `generator.py` so
neither native resource loading nor ordinary generation imports sibling work.
Labels returned by Python are claims; protected Racket executes the retained
preflight, literal regression and adversarial audit labels independently.

From the packet outer directory, with its ready Python interpreter:

```sh
WORK/.venv/bin/python review.py run python3 -m arcpuzzles.review_public_creation preflight public_eval_d59b0160 --root . --out ../checks/public_eval_d59b0160/preflight
WORK/.venv/bin/python review.py run python3 generators/public_eval_d59b0160/workspace/audit_family.py --root . --out ../checks/public_eval_d59b0160/audit-new.json
WORK/.venv/bin/python review.py task-tests public_eval_d59b0160 --phase after --timeout 180 --out ../checks/public_eval_d59b0160-tests
```

Use new evidence destinations on reruns. Any task Python/Racket source change
requires a new preflight and causal witness. `workspace/authoring_preview.py
--help` documents the explicit public-preflight export/verify/self-check flow.
The full query bank, settings, answers, source IDs and private manifest belong
to the controller; send the model only one hash-named public JSON at a time.

Limits: rectangle grammar, fixed structural colors, finite rivals/seeds. Owner
registration and native qualification/acceptance remain separate required steps.
