# 70a3d3e2c975 native parametric family

`copy_policy=all_colors` is the exact canonical Racket program.  The alternative
`rarest_color` first counts source-half colors and mirrors only the unique least
frequent color.  Inputs are setting-neutral, count-prefix-stable, support 2–6
demonstrations and four controller-side queries, and culminate in a substantive
30×29 case (the central full-height axis requires odd width, so 30×30 is outside
this grammar).

Sequential dependency: step A discovers the axis, counts source colors and
produces the eligible color set; step B consumes that set while reflecting cells.
The retained protected witness replaces the full eligible set with the rarest
singleton set and changes the final output.
