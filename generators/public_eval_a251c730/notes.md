# public_eval_a251c730: marker-anchored template transfer

## General rule and native settings
Detect two maximal monochrome rectangular frames despite the striped exterior. Infer each panel's interior background, distinguish repeated 8-connected multicolor templates from singleton target markers, and recover a color-to-template dictionary of occupied cells relative to each unique source marker. Crop the target and stamp matching masks, protecting its border and existing markers. The default `all_templates` exactly equals root `reference.rkt` and reproduces both original demonstrations and the supplied test gold; no source-grid or answer lookup is used. `largest_template` stamps every tied-largest distinct template by occupied-cell count and leaves smaller-template markers intact. Repetition count is not template area.

## Sampling and teaching decisions
The standalone base generator and copied sampler are byte-identical, self-contained files. They vary two/three template types, sparse diagonal-rich versus dense geometry, two-color payloads, off-center anchors, template/marker counts, palettes including zero, equal/different panel backgrounds, striped exteriors, reflection/rotation, and frame location/size. The fourth query is a substantive 30x30 input with content distributed in both panels. Accept 2–6 demonstrations and exactly four distinct queries; demo count never changes the independent query bank. The setting never changes inputs.

Self-review found four shortcut classes: monochrome payload, opaque background rectangle, cardinal-only extraction, and repeated-source-area ranking. The first two demo profiles now contain a changed panel background, mixed payload colors, a diagonal motif with real cardinal neighbors, and source-count/area inversions. Bounded input-only rejection also reverses numeric-marker and source-order correlations. It sees no query input or answer. The saved seed-7 opaque-copy counterexample has protected-Racket labels and can be replayed with `checks/public_eval_a251c730/replay_shortcut.py` after the repair. The 32-seed audit passes 192 lessons / 1,472 pairs with 23 explicit policies; finite equivalences and the lack of universal uniqueness remain explicit.

## Domain and handoff limits
Frames have at least five cells on each side, a background unlike their border, and the upper-left interior cell unlike that border. The source has repeated consistent 8-connected motifs with one matching marker each; the target initially contains separated singleton markers. The constructive sampler avoids overlapping stamps and covers a bounded subfamily rather than all possible ARC templates. Painting protects borders/markers; clipping is explicitly tested. Finite audit predictions are Python claims; originals, preflight, boundary and causal evidence are protected Racket.
