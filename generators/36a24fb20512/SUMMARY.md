Grid with 1-3 solid 2×2 color-3 blocks and 1-3 solid 2×2 blocks of OTHER colors as decoys. Rule: count the number of (overlapping) solid 2×2 sub-blocks of color 3 (sliding 2×2 window). Output is a fresh 3×3 grid: cell (r, r) = 1 for r in 0..count-1, all other cells = 0. So the output is a diagonal of 1s of length = count.
