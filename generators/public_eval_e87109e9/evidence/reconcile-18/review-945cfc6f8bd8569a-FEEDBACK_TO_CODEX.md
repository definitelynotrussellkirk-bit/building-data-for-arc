# Tooling feedback

## F1: Biggest avoidable friction: public-creation evidence was fragmented across several commands

The protected preflight correctly writes the source inventory and official-pair execution, but causal replay, finite-rival audit, public projection/privacy checks, saved-export checks, and their command receipts still require separate manual orchestration. A single `review_public_creation qualify-local TASK --out ...` command that runs these bounded reviewer gates and emits a canonical evidence index would reduce stale-path mistakes while preserving the explicit distinction from owner qualification and acceptance.
