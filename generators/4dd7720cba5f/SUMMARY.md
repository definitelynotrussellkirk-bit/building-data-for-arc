# 4dd7720cba5f

Split the zero-separated grid into 5x5 framed tiles. For each frame color,
union every local interior offset occupied in any same-color tile, then paint
that complete union into every tile of the color.

Version `4.0.0` adds scheduled multi-source profiles: one same-color motif is
split across two source tiles, so the generated curriculum distinguishes true
union semantics from canonical-fitting shortcuts that copy only one source or
fill only blank peers. The canonical Racket rule and pinned `RULE_HASH` are
unchanged; selected authority text is synchronized byte-for-byte to canonical.

Kind: `per_puzzle`. Approval is derived by the catalog from current code and
retained evidence.
