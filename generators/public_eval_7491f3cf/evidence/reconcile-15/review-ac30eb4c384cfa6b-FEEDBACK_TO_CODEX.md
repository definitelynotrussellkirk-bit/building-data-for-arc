## F1: Biggest avoidable friction: witness templates can select a no-op counterfactual

The template selected the first nondefault episode while the adapter's authored counterfactual was that same nondefault program, so protected build failed only after a full replay. When `causal_settings()` or `counterfactual_program()` is available, the template should choose a compatible episode or reject identical program hashes before writing the draft.
