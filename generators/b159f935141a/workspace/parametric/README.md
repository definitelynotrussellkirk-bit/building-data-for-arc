# Rarest-color plus-completion family

`fill_scope=all_qualifying` returns the exact canonical Racket program and fills
every hollow monochrome cardinal plus. `fill_scope=rarest_color_only` first
finds all qualifying centers, counts them by arm color, selects the unique
rarest color, and fills only centers of that color. Inputs are matched across
settings and include the original local conjunction demands plus horizontal,
vertical, three-arm, mixed-arm, occupied-center, and diagonal decoys.

The sampler supports 2–6 demonstrations, four distinct queries, and a substantive
30×30 query. The causal witness replaces the rarest-color intermediate with the
most-common color and requires a different protected-Racket output.
