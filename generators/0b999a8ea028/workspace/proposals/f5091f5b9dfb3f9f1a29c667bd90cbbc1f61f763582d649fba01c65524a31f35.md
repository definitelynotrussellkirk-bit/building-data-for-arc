## Intended rule

1. Find monochrome, nonzero, 4-connected components.
2. Treat a color-1 component as a destination only when its cells are exactly the border of its bounding rectangle.
3. Select the largest non-color-1 component as the prototype; stable scan order resolves ties in the selected rule.
4. Normalize the prototype to its bounding box.
5. Rebuild a blank grid and center one prototype copy inside each exact frame interior using Racket `quotient` centering.
6. Erase all source objects, frames, decoys, and malformed blue components. If there is no exact frame, return a blank grid.

The v3 Python `rule_mirror` matches all three canonical input/output pairs. Native Racket parity could not be rerun in this environment; that limitation is retained rather than converted into a claim.

## Implemented changes

### Four-profile curriculum

Every four consecutive natural sample indices now cover exactly these profiles:

1. `canonical`: one 3/4-cell prototype and two or three exact 5x5 frames.
2. `size_contest`: a smaller scan-earlier decoy, a larger five-cell prototype, and an exact 7x7 frame. This jointly refutes first-object selection, fixed-5x5 frame recognition, and top-left placement.
3. `nonframe_blue`: an exact 6x6 frame plus a one-cell-broken 5x5 blue ring. Only the exact frame is a destination.
4. `no_frames`: one connected blue component made from two touching apparent frame outlines. It is not an exact rectangle border, so the answer is blank.

The schedule is `sample_index % 4`; it does not depend on global random state and is stable across difficulty bands.

### Explicit source contract

The generator now declares:

- `VERSION = "3.0.0"`
- `RULE_HASH = "d8a130fd2a56"`
- `EXAMPLES_NEEDED = 4`
- exact axes for `grid_h`, `grid_w`, and `texture`
- `SCHEDULE_PROFILES`
- `strict_canonical_like`
- `SEMANTIC_RIVALS`, `CANONICAL_SHORTCUTS`, `LESSON_COMPETITORS`
- `SEMANTIC_WITNESSES`, `WITNESS_RIVALS`
- `lesson_identifiable`
- `observe_overrides` and `semantic_signature`
- mutation fixtures for a one-cell-broken exact frame

A pure Python component analyzer and rule mirror make the intended structural choices directly testable without embedding game answers in the generated grids.

### Override repair

- Legal ranges are now genuinely available in every band: `grid_h=11..18`, `grid_w=11..20`.
- Every endpoint/texture Cartesian combination is constructible.
- Requested values are observable from the returned grid.
- Unknown override keys raise `ValueError`.
- No undeclared incompatibility exceptions remain.

Natural draws are strongly biased toward the public 11/12/13 square manifold, while explicit overrides retain every declared endpoint.

### Stronger validation

`self_check` now verifies rectangular grids, dimensions, component counts, unique prototype size, frame fit, profile-specific morphology, one-cell-broken rings, connected no-frame composites, and requested override realization. It no longer rejects valid blank-output negatives merely because no exact frame exists.

## Remaining issues and uncertainty

1. Native Racket execution parity was not measured here. `rule_smoke`, Racket-backed validation in `lint`, rule-dependent `defect_lint`, authoritative `semantic_gate`, and execution parity in `authority_sync` remain blocked by the same missing runtime.
2. The Python mirror is source-reviewed against the selected Racket body and matches every canonical pair, but this is not a substitute for running the Racket implementation on generated cases.
3. The curriculum deliberately guarantees semantic coverage in four examples. This improves identifiability but is less stochastic than v2; consumers wanting arbitrary independent sampling should treat `sample_index` as the curriculum position.
4. Shapes and placements are intentionally compact and deterministic enough to make contracts auditable. Further aesthetic/layout diversity can be added after Racket parity is available, but should preserve the four semantic obligations.
