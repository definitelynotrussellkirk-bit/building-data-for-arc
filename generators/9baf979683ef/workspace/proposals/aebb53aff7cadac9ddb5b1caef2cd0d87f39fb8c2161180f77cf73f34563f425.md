## Implemented repair

The repaired generator pins the selected authority, rejects unknown or mistyped overrides, and exposes only `grid_h=5..14`, `grid_w=7..17`, and `left_cell_count=3..10`. `observe_overrides()` recovers all three values from returned pixels, and every boundary/joint combination is constructive in every difficulty band. Difficulty now biases sampling frequency while leaving the complete declared domain available to explicit overrides.

The input distribution now includes centered and off-center full-height color-5 dividers, two- and three-color examples from canonical `{2,3,4}` and extended `{1,6,7,8,9}` palette families, and scattered/connected/snake source layouts. All source cells remain strictly left of the divider and have in-bounds right-side reflections. A structural validator accepts all three canonical inputs, rejects malformed or out-of-domain grids, and is reused as `strict_canonical_like`.

The semantic contract declares three canonical-fitting rivals: assume the divider is at the grid center, process canonical colors only, and process only the first two object colors. The four-example profile cycle is:

1. centered / canonical palette / two colors;
2. centered / extended palette / three colors;
3. off-center / canonical palette / three colors;
4. off-center / extended palette / two colors.

Each witness attribute appears twice, so removing any one example as the query still leaves a demonstration that refutes each rival. The layout cycle uses four scattered, one connected, and one snake slot; this retains lawful morphology diversity without collapsing the nonzero-component median away from the canonical task.
