0-bg grid with N (2-6) isolated 4-conn components in distinct colors. Components are partitioned into shape-equivalence groups: members of a group share an identical normalized binary mask (random polyomino), groups differ. Rule sorts components by (col,row) and emits an NxN matrix with 8 where shape r == shape c, else 0. N varies so the output size and the equivalence pattern both vary widely.
