# 2ab8c1aaa3e2 — exact-two vertical markers, v2.0.0

For each column and each nonzero color, fill its inclusive vertical span only
when the original input contains exactly two occurrences of that color in that
column. Triples and unlike-color endpoints do not join. An interior unlike
singleton is overwritten by a true pair. The canonical Racket program remains
the only label authority, pinned as `ad1f1fa8669a`.

Ordinary samples alternate one canonical-like core with two complete contrast
examples. Color identities and columns are randomized; broad support is mixed
with canonical dimensions rather than copying canonical grids. Every four
consecutive default draws include at least two complete contrast examples.
Three demonstrations therefore refute all four declared rivals even when any
one of those four draws is held out. This is not universal identifiability or
an arbitrary-override curriculum guarantee.

Exact controls: `grid_h=4..22`, `grid_w=4..20`, `pairs=1..12`,
`n_distinct_colors=1..9`; jointly infeasible settings raise a structured error.
Legacy inert palette/density/position/texture controls are removed, not ignored.
