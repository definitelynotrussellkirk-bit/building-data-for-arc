# Native `normalization_anchor` family

The canonical `top_left` setting is byte-for-byte the selected authority.  The
`relative_corner` setting first locates the smaller object relative to the
larger one, then aligns both normalized masks to that input-derived corner before
performing the original exact-mask subtraction.  The first two demonstrations
span independent row and column choices; four private queries are generated as a
complete bank, shuffled privately, and exposed one at a time.

`audit.py` is the reusable bounded teaching and protected-Racket audit.  Native
qualification and the source-bound causal witness remain the acceptance evidence.
