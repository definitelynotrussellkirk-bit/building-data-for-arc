# Native parametric family: `0ff4b77946cc`

`order_policy=size_desc` is the exact canonical program.  The alternate
`largest_orientation` first identifies the largest object and measures its
bounding-box orientation.  A wide or square largest object selects descending
size order; a tall largest object selects ascending size order.  The selected
order is then consumed by the unchanged top-aligned gallery packer.

The demo bank begins with one wide and one tall largest-object case, so the
minimum two-demo lesson exposes both branches.  Demo and query banks are
separate, every episode has four stable private queries, and one query is a
30x30 stress case.  `wrong_always_desc.rkt` is the declared causal ablation for
tall cases.  Evidence is finite authoring evidence only; owner acceptance and
training admission remain separate.
