`header_policy=row_local` is the exact selected canonical program: each interior
8 takes its own row's nonzero left header. `header_policy=densest_source` first
selects the eligible row with the greatest number of interior 8s, carries that
row's header color as the episode input-dependent intermediate, then recolors
every interior 8 with that color. Generated scenes avoid selector ties.

The adapter accepts 2–6 demonstrations and 1–4 queries independently. Inputs are
identical across settings for a fixed seed/count request, demo/query prefixes are
stable, the first two demonstrations distinguish the settings and named shortcut
rules, and the fixed four-query bank ends with a content-rich 30×30 scene. Pair
labels are deterministic Python claims; native qualification independently
re-executes every label through protected Racket.

The bounded `audit.py` checks matched inputs, two-demo identifiability, changing
selected colors, a finite shortcut bank, distinct pairs, and the 30×30 case. It
does not establish universal uniqueness or measured training benefit.
