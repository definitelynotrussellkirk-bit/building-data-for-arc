# 0d191ce876ab native parametric family

`preprocess=identity` preserves the byte-exact canonical program.
`preprocess=merge_1_into_2` first maps every input colour `1` to `2`, then runs
the same local four-neighbour survivor filter.  The intermediate grid therefore
depends on the visible input and is consumed by the shared second stage.

Inputs are sampled independently of the hidden setting.  Every two-demo lesson
constructs split-colour pluses, colour-1 pluses, mixed 3x4 rectangles,
multi-core solids, an unaffected colour-6 core, and a mixed-colour occupied
near-core.  Together these make both settings identifiable while refuting the
historical one-centre-per-object shortcut, a post-merge occupied-neighbour
shortcut, and a constant-colour survivor shortcut.
