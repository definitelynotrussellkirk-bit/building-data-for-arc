# Native parametric family

- `stamp_only` is the byte-exact canonical crop-and-stamp rule.
- `stamp_majority_frame` first relocates the tight crop to the marker, derives
  the unique majority color of that stamped intermediate, and draws a one-cell
  exterior frame at the destination.

The family supports 2–6 demonstrations and 1–4 query prefixes. The complete
private bank always contains four distinct queries; query 4 is a substantive
30×30 case with an 80+ cell connected source.
