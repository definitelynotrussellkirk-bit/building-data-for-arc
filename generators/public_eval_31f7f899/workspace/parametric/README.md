# Ordered bar-height family

The unique fully occupied horizontal carrier row contains solid rectangular bar
slots. Step A measures each slot's input height and sorts the height vector.
Step B redraws the same colored, same-width slots around the carrier using the
ordered heights. `height_order=ascending` is the exact public-parent rule;
`descending` is the matched-input alternative. Even heights use one more cell
above the carrier than below, matching the canonical task.

The constructive bank has six demonstrations and four independently shuffled
queries, supports 2–6 demo prefixes and 1–4 query prefixes, varies palettes,
carrier position, repeated colors, widths and counts, and includes two distinct
30×30 scenes. Settings and labels stay private. This is an unapproved authoring
prototype pending owner registration, qualification and acceptance.
