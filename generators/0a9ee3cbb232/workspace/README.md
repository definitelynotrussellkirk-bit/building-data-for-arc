# Workspace

The selected implementation is `../generator.py`; workspace files are review tools, not label authority.

- `reference_probe.py` is an independent pixel oracle for horizontal-run counts, the three plausible rivals, canonical-pair loading, override observation, and deterministic lesson materialization.
- `qualify.py` is a fast source-bound qualification tool for future agents. It checks canonical behavior, all 1,440 exact override combinations, default witness coverage, and every cyclic query rotation for a configurable set of lesson starts.

From the packet root:

```sh

  repo/generators/0a9ee3cbb232/workspace/qualify.py \
  --samples-per-band 100 --cyclic-starts 16 \
  --out checks/qualification.json
```
