# 42a28f889145 — Swap Two Object Colors

A `0`-background grid contains exactly two separated, uniformly colored,
four-connected objects in distinct nonzero colors. Sort them left-to-right and
exchange their colors while preserving shape, position, occupied cells, and
background.

Generator version: `3.0.0`. Canonical rule hash: `57cc84264d9e`.

The generator exposes four exact, observable controls: grid height (7–12), grid
width (9–16), ordered shape pair (36 values from six 3–6-cell shapes), and
unordered color pair (36 values from colors 1–9). Consecutive lesson pairs
alternate numeric color order so every three-demo/four-pair lesson refutes the
canonical-fitting shortcut “sort colors descending from left to right.”

task directory. Approval remains catalog-derived from code and evidence; this
