# Task-local authoring tools

The selected production implementation is `../generator.py`. These tools do not
select or approve a new generator automatically.

- `verify_transpose.py` executes the unchanged canonical Racket rule on the five
  supplied pairs, requested-size lessons, and an occupied-partner boundary. It
  saves exact labels, source/program hashes, accepted indices, and demonstration-
  only rejection evidence for six concrete rivals. Run it with separate `--demos`
  and `--queries` counts and a new `--out` file; current notes give the command.
- `parametric/inspired_template_expansion.py` is the separate proposed
  `65b59efc`-inspired extension. Its README gives the fixed episode parameter,
  bounded grammar, Racket-backed four-query commands, and public/private export
  contract. It is not a canonical E38 variant or an accepted production family.
