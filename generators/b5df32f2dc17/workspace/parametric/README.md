`length_order=descending` is the exact selected canonical rule. The
`ascending` setting changes only the input-derived run-length ordering while
retaining row-local extraction, original-start tie breaking, mandatory left
repacking, and one-cell separators. Every scene includes reorder rows,
offset controls already ordered in both directions, a singleton control, a tie
row, and a blank row.
