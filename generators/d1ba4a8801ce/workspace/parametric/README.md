# Proposed framed-block shelf-axis variants

This task-local prototype preserves the checkerboard restoration, dominant
rectangular frame, and loose rectangular content-block inference. It changes one
episode-fixed rule parameter:

| `shelf_axis` | Executed transformation |
|---|---|
| `long` (canonical default) | Center and shelf blocks along the frame's long axis. |
| `short` | Center and shelf blocks along the frame's short axis. |

Inputs are identical across settings and every generated frame is non-square,
so the two programs are behaviorally distinct. Episodes have 2–6 demonstrations
and 1–4 queries independently. The query schedule includes an 11×13 minimum
case and a substantive 30×30 case whose frame disruptions cross all quadrants.
The default program is byte-for-byte the selected canonical Racket authority.

Because the production generator is currently unapproved, this prototype does
not modify it and is not training-admitted. Evidence is generated by invoking
the protected parametric worker directly against the finite task-local contract.
`episode_io.py` provides strict atomic sequential public/private export with
hash verification, duplicate-visible refusal, and no public settings, answers,
programs, seed, query index, or total-query hint.
