# Three exact selection strategies over a shared anchored grammar

The legacy parameter key`target_degree`retains exact integer values0(default)
and1. A third typed string value`anchor_area`selects the occupied-area rule;
it is not degree2,an alias,or a Cartesian interaction. All three exact authored
Racket program strings and the canonical generator remain unchanged.

Every strategy uses the same incoming anchored input bank: one color3anchor,
isolated color2cells,anchor-sized and near-area color2components,large components,
same-area color4distractors,and diagonal contacts. The first2demos vary anchor
size. One retained old boundary-singleton motif is added at the first empty
boundary cell with no eight-neighbor color2contact; this restores boundary vs
interior teaching without changing the color3anchor or non-singleton areas. The old no-anchor bank cannot be used unchanged for the area rule,so its
source module/sampler remains intact as a capsule rather than emitting illegal
new-rule inputs. Degree programs ignore other colors; labels for the broadened
grammar execute in protected Racket instead of using the old0/2-only mirror.

Inputs are setting-independent and count-prefix-stable;2–6demos and1–4queries
are supported. Query3is a substantive30×30boundary scene,query4is24×29.
One-query public views whitelist demonstrations and one query input and hide
private settings,programs,answers,future inputs and total-count hints.

`prototype.py`/`degree_adapter.py`retain original degree helpers/programs/tests;
`anchor/`retains the incoming source sampler/program/rival bank unchanged.
The bounded union audit checks both old degree and incoming component rivals
against every selected rule. This evidence is finite and grants no training
admission. Current live acceptance remains untouched until owner qualifies and
accepts the complete exact union source.
