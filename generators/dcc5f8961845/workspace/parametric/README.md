# Parametric command-source family

- `second_source=header` preserves the selected canonical Racket program byte-for-byte.
- `second_source=post_first_marker` applies header command one, observes the unique
  color-9 marker's corner in that intermediate grid, then chooses the transform
  that moves that post-first marker to the top-left.

Both settings receive identical deterministic inputs. The first two demonstrations
are constructive teaching cases; later demonstrations add size and texture. Query
four is a real 30x30 input with a 28x30 motif touching three canvas boundaries.
Private settings, programs, and query labels remain outside public projections.
