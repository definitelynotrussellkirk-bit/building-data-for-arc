# Workspace

The selected implementation is `../generator.py`; workspace files are review aids and are never selected automatically.

- `IMPLEMENTATION_PLAN.md` / `IMPLEMENTATION_LEDGER.md` — scoped repair plan and execution record.
- `probe_generator.py` — portable source-bound audit of canonical parity, exact controls, schedule/witness coverage, rotated lesson identifiability, and diversity.
- Full baseline, RED/GREEN, probe, battery, census, solve, and audit evidence is retained under the return package's `checks/` evidence bundle rather than mixed into the applied source delta.
