# Native parametric family: translation then cue relay

`finish=translate_only` is the exact selected canonical Racket program.
`finish=cue_payload` first computes the canonical translated yellow footprint,
then reads its unique adjacent cue color and paints that color's local cue plus
remote payload cyan.  Separate cue colors adjacent to the source yellow and the
green marker make the translated footprint a necessary intermediate.

The sampler is setting-independent, supports 2–6 demonstrations and 1–4
queries, and makes the fourth query 30×30.  `audit.py` replays labels and a
wrong-order causal witness through protected Racket. Pass the current native
qualification receipt with `--qualification`; the emitted witness uses the
owner-admission schema and binds the exact qualified source inventory.
