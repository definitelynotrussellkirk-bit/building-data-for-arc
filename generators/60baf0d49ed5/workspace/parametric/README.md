# Native parametric prototype

`promotion.json` selects `adapter.py`, which delegates to the source-bound implementation in `native.py`. `canonical.rkt` is copied exactly from the selected catalog record; `repeat_transform.rkt` is the alternative. `audit.py` performs bounded deterministic, teaching, projection, stress, base-repair, and protected-Racket checks. Canonical packet collection tests live in `../../tests/test_parametric_60.py`.
