# Native parametric family: independent versus cumulative commands

`application_policy=independent` is the exact selected canonical Racket source.
`cumulative` applies each corner command to the previous transformed motif, so
command order changes the intermediate state sequence before the four states are
packed. Inputs are identical across settings. The first two demonstrations
identify the policy; four prefix-stable queries culminate in a dense 30x30 case.

Sequential dependency: step A produces the ordered transformed motif states;
step B measures and packs those exact states. `audit.py` checks the bounded
setting and shortcut curriculum.
