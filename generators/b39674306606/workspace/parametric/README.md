# b39674306606 native parametric family

`frequency_target=singleton` is the exact selected canonical rule. The
`most_frequent` setting keeps exact translation-normalized shape comparison but
paints all instances of the unique most frequent shape class. Every generated
input contains one singleton, one exact pair, and one exact triple on matched
inputs. The singleton is a D4 transform of the pair shape, while the triple uses
a non-D4-equivalent shape with the same area, so size-only and orientation-free
shortcuts are visibly wrong.
