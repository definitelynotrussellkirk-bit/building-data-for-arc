# Four disjoint arm/room rules

The private `component_scope` remains `all_components` (exact canonical
default), `largest_component`, `largest_residual_room`, or `armiest_component`.
All four accepted program strings are unchanged. The room_policy and finish_rule
aliases remain supported. Canonical production is unchanged, and the production
bitmap replay audit remains unresolved.

All settings receive matched fresh four-network scenes on 24–30 square canvases.
The former fixed-six scene construction has been replaced: the first network
supplies its naturally occurring unique residual-cyan maximum (at least three
cells); the other networks must have smaller residual regions. No literal
winning size is selected by the sampler. The current room constructor yields
observed maxima 3, 4 and 6. Network room/tip draws vary independently of the
chosen episode rule, and network positions are shuffled.

The minimum lesson must contain two different observed residual maxima and
jointly reject all 28 retained rivals plus three literal equal-size selectors
(size 3, size 4 and size 6). The fixed-six shortcut is therefore explicitly
refuted. First and second queries must also have different observed maxima;
later query maxima vary freely. This variation gate inspects scene structure,
not the selected episode rule. All four queries are constructed before count
prefixes are taken, preserving count/settings-independent inputs.

Gray-component sizes, the residual-cyan maximum and the classified-red maximum
remain unique; the armiest component must contain cyan cells to highlight.
Networks remain separate under four- and eight-connectivity. The minimum lesson
is selected within 32 attempts before query construction; individual networks
have a 128-attempt bound, and each remaining valid scene a 32-attempt bound.
Exhaustion raises an error. Rival execution errors never count as refutation.

Supports 2–6 prefix-stable demos and 1–4 prefix-stable queries, default four.
Query canvases are 24, 27, 29 and 30 square, with genuine room/arm networks
anchored across all four corners. Previous source implementations and samplers
remain available in retained_union.py, prototype.py and residual_family.py.

Focused evidence is finite: 32 seeds, all four settings, all 31 declared rivals,
fixed-size regression checks and protected Racket label replay. It does not
prove universal identifiability. Fresh owner qualification and acceptance are
required for these changed sampler bytes; training admission remains separate.
