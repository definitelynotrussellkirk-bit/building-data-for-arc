# b37eb391ddc0 reviewer workspace

`reference_probe.py` is a source-bound, replayable supplementary audit for this
generator. It checks canonical acceptance and Python-mirror labels, every public
profile, all declared witnesses and rivals, determinism, per-band uniqueness,
foreground object counts, and every query rotation of consecutive three-pair
lessons. The `--racket` mode stages and executes the selected canonical Racket
rule and never silently substitutes the Python mirror.

From the review packet root:

```bash
python3 run_with_racket.py python3 \
  generators/b37eb391ddc0/workspace/reference_probe.py \
  --count 100 --racket \
  --out ../checks/reference-probe.json
```

The finite rival set is deliberately explicit. A passing report is evidence
against those named shortcuts, not a proof that no other induction can fit a
lesson.
