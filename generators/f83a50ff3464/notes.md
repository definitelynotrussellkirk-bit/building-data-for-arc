version 2.0.1 generator had a broad declared control surface that it did not
honor, generated mostly far outside canonical morphology, and had no executable

all canonical positive centers have four equal arms, and no canonical input has

1. `_place_noise(..., count=0)` did not return before its placement loop, so it

   vertical-pair/horizontal-pair rival. The third canonical input naturally
   contains two adjacent-pair 2+2 neighborhoods between diagonal pluses; these
   are lawful and do not satisfy the rival.

`workspace/shortcut_probe.py`. The full after battery is retained under

# Decisions: `f83a50ff3464`

## D1 — Keep the selected Racket rule unchanged

**Choice.** Preserve rule hash `14c360998abe` and build an independent Python
mirror.

**Original rationale.** The original generator supplied no explicit rationale
for the authority. The canonical written solution, all four canonical pairs,
the selected Racket source, and baseline rule smoke all agreed on the same
four-equal-cardinal-neighbor rule.

**Alternatives considered.** Restrict execution to visually isolated crosses;
interpret connected objects rather than local neighborhoods; edit the Racket
source to reject incidental arrangements.

**Probe.** Exact canonical execution, 120 after-battery mirror comparisons,
Racket execution parity, and the compact `3+1` probe.

**Failure modes / limits.** The authority is intentionally broader than the
training morphology: any lawful grid may contain a firing local neighborhood.
The finite generator curriculum is not the mathematical domain boundary.

## D2 — Replace broad free axes with one exact `scene_profile`

**Choice.** Remove ten advertised controls and expose twelve finite profile
values through one axis.

**Original rationale.** Unknown. Version 2.0.1 declared dimensions, palettes,
counts, density, position bias, distinct-color count, and texture, but generation
consulted only band ranges, a private RNG, and a degenerate texture branch.

**Alternatives considered.** Implement every old axis independently; keep the
old surface but mark most axes diagnostic; expose separate exact axes for every
profile property.

**Probe.** The baseline override matrix produced 17,020 findings. The final
matrix accepted and observed 1,170/1,170 draws with zero findings and rejected
an unknown key.

**Failure modes / limits.** Finite profiles reject unsupported combinations
rather than synthesizing all Cartesian products. Adding a profile requires a
new uniquely observable signature and schedule review.

## D3 — Stay inside the canonical 7–9 by 7–9 geometry envelope

**Choice.** Use only 7x7, 7x9, 8x8, and 9x9 boards.

**Original rationale.** The old difficulty bands expanded as far as 20x22,
which caused medium and hard to have zero exact canonical-profile support.

**Alternatives considered.** Keep a large hard band; use only exact source
shapes; scale motifs proportionally to larger canvases.

**Probe.** Before profile floor was 1/60 exact and 4/60 envelope. After was
27/60 exact and 36/60 envelope, with all four canonical inputs accepted.

**Failure modes / limits.** Large-canvas generalization is no longer trained.
The chosen shapes prioritize source fidelity over scale extrapolation.

## D4 — Put two or three true centers on every ordinary board

**Choice.** Profiles contain exactly two or three firing centers.

**Original rationale.** Canonical examples contain two or three targets. The
old code allowed much larger counts in hard mode and only required one.

**Alternatives considered.** Permit one target; use up to seven as before; make
count a separate override.

**Probe.** Structural analysis and `_fires == intended` realization gate;
strict validator accepts only 2–3 targets; canonical and all profiles pass.

**Failure modes / limits.** The generator does not train very crowded boards or
single-target scenes. Those remain lawful for the rule but outside this
curriculum.

## D5 — Use a four-slot adversarial curriculum

**Choice.** Each band schedules clean, `3+1`, opposite-pair `2+2`, and
three-arm-partial profiles in that order modulo four.

**Original rationale.** Version 2.0.1 randomly chose only partial or
four-distinct-arm decoys. It had no guarantee that a lesson included any
specific discriminating case.

**Alternatives considered.** Random decoy mixtures; one profile containing all
near misses; eight-example lessons; rely on dataset-scale diversity without a
schedule.

**Probe.** Every consecutive four-demo window for eight starting offsets in
all three bands passes task tests; semantic gate reports 12/12 requested
lessons identifiable.

**Failure modes / limits.** A consumer that shuffles or truncates below four
examples can lose the guarantee. Only one explicit near miss appears per
profile.

## D6 — Treat `3+1` majority as the primary shortcut witness

**Choice.** Add a fully visible four-arm near miss with three equal colors and
one outlier.

**Original rationale.** No canonical example or old generated decoy separated
four-way equality from a three-of-four majority.

**Alternatives considered.** Four distinct colors only; a `2+1+1` split; a
missing arm; an outlier of background color.

**Probe.** The compact exact input in `QUESTION_ANSWER.md` was executed through
the selected Racket authority and left unchanged; the rival fills its center.
Generated `3+1` witness fired 138/600 times and the claim was verified 60/60.

**Failure modes / limits.** This witnesses the equality threshold but not every
possible color-frequency heuristic.

## D7 — Distinguish opposite pairs from arbitrary `2+2` color splits

**Choice.** A `two_plus_two` witness requires `up == down`, `left == right`, and
different vertical/horizontal colors.

**Original rationale.** The semantic rival is specifically an
opposite-direction pairing rule.

**Alternatives considered.** Classify every two-color 2+2 arrangement as the
same witness; add adjacent-pair and diagonal-pair rivals separately.

**Probe.** The third canonical input contains two incidental adjacent-pair
2+2 neighborhoods. The broad classifier made canonical strict validation fail;
the orientation-specific classifier accepts canonical data while generated
opposite-pair profiles still refute the rival 60/60.

**Failure modes / limits.** Adjacent-pair heuristics are not separately named.
They already do not induce the registered opposite-pairs output.

## D8 — Include repeated target colors

**Choice.** Every majority profile has at least two true centers sharing one
arm color.

**Original rationale.** Canonical target colors are distinct within each board,
so “complete at most one center per color” fits every source pair.

**Alternatives considered.** Repeat colors in every profile; use a dedicated
fifth schedule slot; repeat a decoy color only.

**Probe.** `one_center_per_color` matches all canonical pairs. The repeated
color witness fired 138/600 times and its rival claim disagreed 60/60.

**Failure modes / limits.** Repetition is paired with the `3+1` profile, so a
learner may correlate those features unless it sees enough randomized scenes.

## D9 — Permit zero to two isolated distractor cells

**Choice.** Some medium/hard profiles add one or two non-target-color cells
outside every motif moat; clean easy profiles add none.

**Original rationale.** One canonical board contains isolated distractors. The
old generator had no explicit source-shaped noise control.

**Alternatives considered.** No noise; dense random noise; distractors using a
target color; a separate noise axis.

**Probe.** Observer signatures include exact isolated-noise count; all twelve
profiles round-trip. Profile and semantic gates remain green.

**Failure modes / limits.** Distractors are always isolated and sparse, so the
curriculum does not cover structured irrelevant objects. Noise colors exclude
target colors, avoiding accidental new firing centers but reducing ambiguity.

## D10 — Separate motif centers by Chebyshev distance at least three

**Choice.** Place motifs with disjoint 3x3 neighborhoods.

**Original rationale.** The old Manhattan-distance gate could allow arm
interactions; exact profile observation needs each intended near miss to remain
recognizable.

**Alternatives considered.** Allow overlaps and solve by rejection; reserve
fixed quadrants; use Manhattan distance four.

**Probe.** `_fires == intended`, exact observer signature, 100% unique inputs
and outputs over 300 pairs, and no generation failure in the 600 semantic draws.

**Failure modes / limits.** Overlapping-cross reasoning is not trained. Some
incidental lawful neighborhoods can still occur between motifs and are treated
as background unless they match an exact registered witness.

## D11 — Return immediately for `noise_count == 0`

**Choice.** Short-circuit `_place_noise` before enumerating candidates.

**Original rationale.** This is a defect fix, not a design preference. The
first implementation checked `len(placed) == count` only after painting, so a
zero request painted every eligible cell.

**Alternatives considered.** Check the target count at the top of each loop;
rewrite placement as slicing from prevalidated candidates.

**Probe.** The failing profile-round-trip test reproduced the issue on
`e_clean_7x9`; after the short circuit all twelve profiles and all schedule
windows pass.

**Failure modes / limits.** Positive noise placement is greedy and may retry a
whole scene if the exact signature is not realized.

## D12 — Use a broad rule-domain `self_check` and a narrow strict hook

**Choice.** `self_check` accepts any well-formed nonidentity input in the rule
domain; `strict_canonical_like` adds 7–9 dimensions, 2–3 targets, sparse noise,
and at most one exact negative-control motif.

**Original rationale.** A local rule is mathematically meaningful beyond the
selected profile grammar, but training quality needs a source-shaped strict
manifold.

**Alternatives considered.** Make `self_check` enforce only the twelve profile
signatures; accept any rectangular ARC grid; put every restriction in
`generate` only.

**Probe.** Canonical acceptance 4/4, strict 600/600, and exact override
round-trips. Generic mutation sensitivity was also inspected.

**Failure modes / limits.** Generic mutations that remain lawful local-rule
inputs are accepted; the after harness rejected 15/61 mutations. This is
reported rather than hidden.

## D13 — Require four demonstrations for lesson identifiability

**Choice.** Set `EXAMPLES_NEEDED = 4`, one complete curriculum cycle.

**Original rationale.** No fixed number was previously declared. Four is the
smallest schedule length that guarantees all four named rival families are
witnessed with the chosen one-near-miss-per-profile design.

**Alternatives considered.** Two dense demonstrations containing multiple
witnesses; three profiles by merging repeated-color and a near miss; five or
more examples for redundancy.

**Probe.** All tested consecutive windows pass in task tests and semantic gate.

**Failure modes / limits.** Fewer demonstrations are not guaranteed to identify
the rule; external samplers must preserve contiguous schedule coverage or
construct equivalent witness sets.

## D14 — Add a reviewer-facing semantic probe

**Choice.** Keep `workspace/shortcut_probe.py` beside the generator but outside
the selected runtime.

**Original rationale.** Prior evidence had no reusable way to answer “which
rivals fit canonical data and where are they falsified?”

**Alternatives considered.** Encode all reporting only in tests; add another
shared repository tool; document manual commands.

**Probe.** The script emits valid JSON, reports all four canonical fits true,
finds one counterexample per witness, and reports zero schedule-window
failures. Output is retained in `checks/shortcut-probe.json`.

**Failure modes / limits.** It imports private generator symbols and is meant
for review, not as a stable public API. It relies on the local canonical file.
