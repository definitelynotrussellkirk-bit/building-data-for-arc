# d3ace3f5d190

Reflect every nonzero cell across the main diagonal. At each output position,
a nonzero reflected value takes precedence over the original value; therefore
one-sided marks are copied while conflicting transposed marks exchange colors.

Ordinary generated scenes contain marks above and below the diagonal and a
conflicting transposed pair, ruling out the weaker “copy into blanks only”
shortcut.

Kind: `per_puzzle`. Generator version: `2.0.0`.
