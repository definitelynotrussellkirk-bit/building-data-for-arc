# Copy-color-role parametric prototype

This task-local prototype varies exactly one episode-level parameter:

- `copy_color_role=paint` — the current canonical rule; reflected terrain uses the sparse marker/paint color.
- `copy_color_role=source` — an executable counterfactual; reflected terrain preserves the source/terrain color.

The input sampler is unchanged by the parameter. Every output label, including counterfactual labels, is generated by Racket. Public episode files contain three demonstrations and one unlabeled query; parameter values, programs, and query answers remain under `private/`.

From the repository root:

```bash
PYTHONPATH=shared/runtime python generators/6d33e42a400d/workspace/parametric/prototype.py \
  materialize --seed 0 --out /tmp/6d33e42a400d-copy-color

PYTHONPATH=shared/runtime python generators/6d33e42a400d/workspace/parametric/prototype.py \
  verify --out /tmp/6d33e42a400d-copy-color
```

The output directory must not already exist. This is review evidence, not canonical or production approval.
