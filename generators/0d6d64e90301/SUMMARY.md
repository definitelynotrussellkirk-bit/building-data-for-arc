Canonical-scale 3×3..5×5 zero-background grid containing one sparse,
4-connected motif in exactly two nonzero colors. Rule: replace **each** input
cell by a solid 2×2 block of the same color, so an `h × w` input becomes a

rectangle, and one tall rectangle. This keeps canonical square support while

rectangular witness against the strongest canonical shortcut, “upscale square
inputs only.” Generated scenes also reject whole-row tiling, whole-grid tiling,
and transpose-before-upscale aliases.
