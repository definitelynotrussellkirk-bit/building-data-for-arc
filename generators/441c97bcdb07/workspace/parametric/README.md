`span_directed_turn` first infers whether the source-copy rectangle is wider or
taller, then rotates the missing fourth copy clockwise or counterclockwise.

2–6 demonstrations and 1–4 queries; the fourth query is an exact 30×30 stress
case with a 25-cell connected motif and source copies touching three boundaries.

visible-only public turns, prefix-stable counts, and a protected-Racket
wrong-intermediate witness. It is finite evidence, not universal uniqueness.
