# Feedback to Codex

## F1 — Treat semantic controls independently

The source rule detects row and column boundaries independently, but the prior
profile design bundled their regularity. When adding or reviewing generator
axes, enumerate the Cartesian product of lawful control states before deciding
which combinations to omit. Add at least one counterexample for every omitted
combination that would otherwise enable a shortcut.

## F2 — Test through the packet's portable runtime

Repository-relative `Path(...).parents[n]` assumptions can pass locally and
fail under task isolation. Use `reviewer_support.find_root`,
`canonical_pairs`, and other packet-provided locators. Make the portable task
stage an early gate, before long batteries.

## F3 — Derive provenance pins from the selected authority

A hard-coded rule hash becomes stale when canonical selection changes. Tests
should recompute it from the selected normalized program and compare it with
the generator pin. Prefer a small helper that owns normalization so generators
and audits cannot drift.

## F4 — Record interrupted batteries as resumable evidence

The baseline battery completed lint, self-check, and rule smoke before the
outer execution wrapper interrupted it. Preserve the checkpoint and resume it;
do not restart completed stages or report the interrupted run as a clean
failure.
