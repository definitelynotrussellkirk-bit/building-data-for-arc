# Native anti-diagonal rank-relay family

The default `copy_only` setting is the exact canonical rule. The alternative
`largest_after_copy` first copies every source across the anti-diagonal, then
selects the unique largest monochromatic 8-connected object in that intermediate
and recolors it yellow.

The sampler constructs a rank inversion: a source-side distractor is largest
before copying, while a smaller diagonal cluster one cell above the axis joins
its reflected copy and becomes largest only after stage A. `audit.py` retains
finite protected-Racket rivals and a wrong-intermediate witness. Owner native
acceptance remains separate and `training_admitted` stays false.
