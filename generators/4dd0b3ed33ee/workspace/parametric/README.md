# 4dd0b3ed33ee native parametric family

`match_selector=first` is the exact canonical authority. Both settings count
blue header markers, form the ordered set of body objects having that many
four-connected enclosed background regions, and then render a tight cyan crop
of the selected object's boundary. `first` takes the first matching object;
`largest_area` takes the unique matching object with the greatest occupied
area.

This is a real sequential dependency:

1. **A — topology filter:** the header count determines an input-dependent
   candidate set via four-connected hole counting.
2. **Intermediate:** the ordered candidates carry areas, positions, colors,
   boundaries, bounding boxes, and connectivity controls.
3. **B — selector and render:** the setting chooses first or unique
   largest-area candidate, then extracts its cyan boundary crop.

The sampler uses matched inputs, 2–6 prefix-stable demonstrations, and exactly
four private sequential queries. The two-demo minimum crosses matching rank,
color, position, motif, and vertical shelf: one lesson places the largest match
below the canonical winner; the other places all matching candidates on the
same shelf. Every scene includes a larger wrong-topology object, a
larger-boundary matching rival, a smaller/fewer-missing-cells rival, multi-cell
holes, and diagonal four-versus-eight-connectivity controls. Query four is a
substantive 30×30 case touching every body boundary.

`adversarial_probe.py` is the reusable bounded verifier. It checks fresh seeds,
2/3/6-demo contracts, malformed inputs and stale program hashes, named
shortcut families, sequential public/private projection, and protected-Racket
parity. Its generated evidence lives under `evidence/`; finite sweeps are not a
universal uniqueness or learning-benefit proof.
