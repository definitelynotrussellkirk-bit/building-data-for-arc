# Shortest-path tie-break parametric prototype

This task-local prototype varies one hidden episode-level setting while preserving the endpoints, walls, shortest-path objective, and cyan path painting:

- `canonical_udlr` — canonical/default; breadth-first neighbors are explored up, down, left, right.
- `horizontal_first` — proposed; breadth-first neighbors are explored left, right, up, down.

Every retained input is generated by the selected production generator, passes its `self_check`, keeps a Manhattan-length route under both settings, and produces different equal-length shortest paths. Episodes support 2–6 demonstrations and exactly four distinct queries. Public files contain only labeled demonstrations and unlabeled query inputs; programs, settings, seeds, and query answers remain under `private/`.

Run focused tests from the repository root:

```bash
PYTHONPATH=shared/runtime pytest -q generators/d3ae93aa8d37/tests/test_parametric_path_tiebreak.py
```

Build real-Racket evidence after activating the packet runtime:

```bash
RACKET_PATH=/absolute/path/to/racket \
PYTHONPATH=shared/runtime \
python generators/d3ae93aa8d37/workspace/parametric/prototype.py \
  --out generators/d3ae93aa8d37/workspace/parametric/evidence
```
