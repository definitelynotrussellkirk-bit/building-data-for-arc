# Native parametric selector family

`selector_measure=marker_count` returns the exact canonical program.  The
alternative `marker_runs` counts horizontal runs of header markers instead.
Both rules first recover an input-dependent panel index and then crop/recolor
that whole candidate cyan.  Episodes support 2–6 demonstrations and stable
1–4 query prefixes; the fourth query is a substantive exact 30×30 case.

`adapter.py` contains deterministic generation, finite rival claims, the
teaching check, and one-query public projection.  Settings, programs, future
queries, and query answers remain controller-side.
