# Reflection-scope parametric family

This source-bound proposal keeps the exact canonical main-diagonal reflection as
`reflection_scope=all`.  The alternative `diagonal_cued` setting first locates
the unique nonzero diagonal cue and reads its color, then reflects only source
cells carrying that input-derived color.  The cue color changes across the
minimum two demonstrations and crosses least/most frequency ranks, so fixed
color and frequency shortcuts cannot replace the cue-discovery stage.

Inputs are identical across settings for the same seed and counts.  The adapter
supports 2–6 demonstrations and a 1–4 prefix of a preconstructed four-query bank.
The full bank covers 8×8, 13×13, 20×20, and a substantive boundary-spanning
30×30 scene.  Every scene has four colors, sources on both sides of the main
diagonal, one diagonal cue, and no occupied transpose pair.

The default Racket program is byte-for-byte canonical.  Protected Racket remains
the label authority during authoring preflight and owner qualification.  This
workspace is reviewer-ready authoring evidence, not owner acceptance or training
admission.
