# Marker-anchor parametric prototype

This task-local prototype varies one hidden episode-level setting while preserving the canonical crop-and-move reasoning:

- `top_left` — canonical/default; the maroon marker is the output crop's top-left.
- `bottom_right` — proposed; the maroon marker is the output crop's bottom-right.

Every retained input is generated by the selected production generator, passes its `self_check`, fits both interpretations without clipping, and produces different outputs under the two settings. Episodes support 2–6 demonstrations and exactly four distinct queries. Public files contain only labeled demonstrations and unlabeled query inputs; programs, settings, seeds, and query answers remain under `private/`.

Run focused tests from the repository root:

```bash
PYTHONPATH=shared/runtime pytest -q generators/ce40117f40f9/tests/test_parametric_marker_anchor.py
```

Build real-Racket evidence after activating the packet runtime:

```bash
RACKET_PATH=/absolute/path/to/racket \
PYTHONPATH=shared/runtime \
python generators/ce40117f40f9/workspace/parametric/prototype.py \
  --out generators/ce40117f40f9/workspace/parametric/evidence
```
