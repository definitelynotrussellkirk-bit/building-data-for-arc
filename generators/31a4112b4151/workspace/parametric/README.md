# `31a4112b4151` target-scope family

`target_scope=all_targets` is the exact selected canonical Racket program.
`target_scope=clipped_targets` extracts the same anchored prototype, computes
which color-9 destinations would lose at least one copied cell at the grid
boundary, and stamps only that input-derived destination set.

The sampler uses identical inputs across settings, supports 2–6 demonstrations
and 1–4 queries independently, and retains a four-query bank ending in a
30×30 boundary-and-spread case. Every pair has two clipped and two unclipped
targets, so the minimum two-example lesson distinguishes the declared settings
and refutes first-target/prototype-only shortcuts. `audit.py` performs a finite
rival audit; protected Racket qualification and the separate causal witness are
the execution authorities.
