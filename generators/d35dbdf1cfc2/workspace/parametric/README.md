# Parametric motif-order prototype

Each input contains three to five isolated colored motifs. Both settings crop each motif, rotate taller-than-wide crops clockwise, and pack them horizontally with one blank column. `size_desc` is the exact canonical program; `size_asc` reverses only the primary size ordering while retaining the color-ascending tie break.

The adapter supports 2–6 demonstrations and independent 1–8 queries. Every constructed input contains at least two motif sizes, at least one tall crop, boundary-spread placement, and a label that separates the two settings. Retained review episodes use four novel queries, including a content-bearing 30×30 case, and execute all labels through protected Racket. This remains a proposal separate from canonical authority, acceptance, and training admission.
