# Review return — two native parametric families

Both assigned task-local families are **ready for owner admission on the exact
packaged sources**.  This return does not perform owner acceptance and does not
admit either family to training.

## `fa3550d200a0` — quarter-turn stamping

The canonical rule remains the exact `quarter_turns=0` default.  The native
adapter supports 0, 1, 2, and 3 clockwise quarter-turns while reusing lawful
production inputs and computing claim labels with an independent Python oracle.
The sampler builds a fixed six-demo/four-query pool before slicing, keeps inputs
matched across settings, and reserves query four for a substantive 30×30 case.

The sequential dependency is: extract every matched object's marker-relative
cell offsets; rotate that intermediate by the selected turn count; stamp it at
the same-colored canvas marker.  Replacing the rotated offsets with unrotated
offsets changes the protected-Racket result in the packaged witness.

Evidence:
- focused native plus retained tests: **56/56**;
- portable changed-target gate: **79/79**;
- native qualification: **8 jobs**, 4 settings × 2 seeds, **128 protected-Racket evaluations**;
- public projection: **32 views**, 48 first-turn invariance checks, 8 positive controls;
- causal witness: `reviewer_replayed`.

The inherited portable fixture was also repaired to use `find_root`,
`canonical_pairs`, and `load_selected_generator`.  This changes test plumbing,
not generator behavior or canonical rule bytes.

## `97d3714964b0` — largest-hollow threshold relay

The byte-exact canonical `independent` policy remains the default.  The new
`largest_hollow_threshold` policy classifies components, computes the largest
hollow bounding-box area, and relays that value as the threshold used to decide
which solid rectangles become red.  Every scene has two hollow frames and two
solids, including one solid at the threshold and one below it; query four is a
30×30 stress scene.

The sequential dependency is: classify objects and select the maximum hollow
bbox area; carry that scalar as a global intermediate; recolor each solid by
comparison to it.  Replacing the threshold with zero changes the final
protected-Racket output in the packaged witness.

Evidence:
- focused native plus retained tests: **65/65**;
- portable changed-target gate: **65/65**;
- strict complete-program validation: **2/2 Racket programs**;
- native qualification: **4 jobs**, 2 settings × 2 seeds, **40 protected-Racket evaluations**;
- public projection: **16 views**, 24 first-turn invariance checks, 4 positive controls;
- causal witness: `reviewer_replayed`.

## Scope and limits

No production generator, shared runtime, or canonical ledger was changed.  The
finite qualification and privacy checks establish exact-source readiness for the
listed settings and seeds; they do not prove universal identifiability, measured
training gain, owner acceptance, or training admission.  The owner must run the
separate fresh admission workflow after integration.
