The canonical default is byte-identical to the selected `9dc70dbec7cf` Racket
rule.  `elbow_order` changes whether each row-major endpoint pair reaches its
bend horizontally or vertically first.  Inputs are matched across settings.

Sequential dependency: A constructs each input-dependent ordered path (including
the canonical duplicate bend cell); B aggregates all A-path cells into a
coverage-count map and converts counts to 3/6/9.  The protected causal witness
uses the opposite route order as a `wrong_order` counterfactual.

The deterministic sampler supports 2–6 demonstrations and 1–4 queries.  Its
four-query schedule ends with a substantive exact 30×30 scene.  `audit.py`
checks a finite set of plausible demonstration-only rivals; this is not a
universal uniqueness proof and grants no owner acceptance or training admission.
