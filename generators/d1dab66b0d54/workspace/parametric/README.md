# Parametric guide-direction prototype

The input contains an equally spaced green guide and a red 3×3 ring centred on an interior guide point. `forward` is the exact canonical program; `backward` reverses only the inferred guide interval. The interior placement makes both settings total over the shared grammar, and every demonstration visibly separates them.

The adapter supports 2–6 demonstrations and independent 1–8 queries. Candidate construction uses a bounded deterministic novelty retry so longer query requests remain distinct without changing shorter prefixes. Retained review episodes use four queries, alternate horizontal/vertical guides, vary interval and guide count, and include a content-bearing 30×30 case. Labels are replayed through protected Racket. This proposal is separate from canonical authority and is not accepted or training-admitted.
