# Parametric family: 99d71aabd753

This family exposes two episode-fixed reasoning choices around the canonical
chart rule:

- `measure`: count connected objects (canonical) or colored cells;
- `alignment`: right-align rows (canonical) or left-align them.

The default `objects/right` program is the exact selected canonical Racket
source. Inputs never depend on the private setting. Every lesson uses three
colors with nonconsecutive object counts, conflicting object/cell score order,
distinct score totals, randomized colors/positions/rectangle orientations, and
four novel queries. The final query is a substantive 30×30 edge-spanning scene.

The causal decomposition is A = derive and sort a color→score table from the
input, then B = render that table with the episode's alignment. Replacing A's
object scores with cell scores changes B's final chart on ordinary inputs.
