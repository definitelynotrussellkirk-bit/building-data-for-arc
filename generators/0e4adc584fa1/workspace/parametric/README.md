# Object-selected control family

`control_selector=last_isolated` is the exact selected canonical program.
`control_selector=nearest_object` measures the non-control object's bounding box,
selects the uniquely closest isolated 1..4 marker, and feeds that marker's code
to the downstream crop rotation. Inputs are matched across settings, count-prefix
stable, and include a substantive 30x30 query.

The finite audit checks declared selector and fixed-code rivals only; owner-side
native qualification and acceptance remain separate.
