# Rotation-scope parametric family

`rotation_scope=all_cells` is the byte-exact canonical 180° rotation.
`rotation_scope=rarest_color_orbits` counts nonzero colors, selects the uniquely
rarest color, and swaps only the 180° cell orbits touching that selected set.
Inputs are matched across settings; the first two demonstrations distinguish the
finite declared family, while four private queries include a substantive 30×30
case. Native qualification independently executes every label through Racket.
