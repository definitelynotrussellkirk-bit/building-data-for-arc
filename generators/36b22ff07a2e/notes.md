## Current parameter proposal

`workspace/parametric/` implements `minimum_marker_area=1|2|4` for the existing
room-compression rule. Count non-background marker cells **within each room**;
small or absent markers become the observed outer background without dropping
rooms. Default 1 returns the exact canonical Racket source. Production source
and canonical authority are unchanged.

Inputs use the same ordered, setting-independent seed stream across variants.
Each lesson includes areas 1, 2, 3, 4, both thin-marker orientations, empty rooms,
and repeated colors across distinct rooms. This teaches inclusive area thresholds
instead of width, height, global color totals, or a fixed background. Certificates
use demonstrations only; threshold-1 rivals that are equivalent on the admitted
grammar remain harmless survivors when they agree on every query.
