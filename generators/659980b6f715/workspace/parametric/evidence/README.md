# Parametric evidence

`current/self_audit.json` is the bounded source-local audit for the native
`alignment_anchor` family. `manifest.json` is regenerated from the final source
and current evidence before qualification. Older `alignment-900/` artifacts are
retained as historical prototype evidence only and are not the current native
qualification.

Public query inputs are separated from private settings, programs and answers.
All findings are finite and reviewer-produced; owner acceptance and training
admission are not asserted.
