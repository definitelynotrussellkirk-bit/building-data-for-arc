# Proposed positive-state rule variant

**Status: proposed prototype, unapproved.** This task-local tool does not alter
`generator.py`, the selected canonical Racket authority, or any approval state.

## Contract

The episode parameter is `positive_state`, with bounded values
`both_zero` and `both_nonzero`. The original/default setting is `both_zero` and
materializes the exact canonical Racket text. The alternative changes only the
cellwise predicate: color 5 marks aligned cells where both halves are nonzero.
The input domain is unchanged. One setting is chosen deterministically from the
episode seed before any pair is generated and is reused for all three
demonstrations and the query.

Every prototype input is generated by the repaired selected generator and
contains all four aligned occupancy states `00`, `10`, `01`, and `11`.
Therefore each demonstration distinguishes the two declared settings. Public
episode files contain only labeled demonstrations and an unlabeled query input;
private files retain the parameter, exact Racket source, query answer, and rival
predictions.

## Run

From the outer extracted packet directory:

```bash
python3 review.py run python3 \
  generators/784b131b3b93/workspace/parametric/prototype.py \
  --seeds 0 2 --out ../checks/parametric/episodes

python3 review.py run python3 -m pytest -q \
  generators/784b131b3b93/tests/test_parametric_variant.py
```

The CLI refuses to overwrite evidence. It checks the exact canonical program
SHA-256, executes every label and rival through the included Racket bridge,
checks all five canonical labels under the default setting, performs a full
deterministic replay, and writes source snapshots and file hashes.

## Limits

This is finite evidence for the retained seeds and the two declared settings.
It does not establish identifiability against undeclared rules, does not provide
a production parametric API, and is not approved training data. Its inputs
depend on the selected repaired generator, so it is not an independent input
distribution.
