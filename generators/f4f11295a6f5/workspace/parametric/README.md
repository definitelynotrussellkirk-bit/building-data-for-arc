# Proposed `tile_color_mode` extension

Status: **unapproved prototype**. The selected canonical generator and Racket
rule remain the `exact` setting; this workspace does not change approval state.

The episode-level parameter is chosen once from:

- `exact` — canonical/default: each nonzero selector emits an exact crop copy.
- `selector` — proposed: each nonzero selector emits the crop occupancy mask,
  recolored with the selector cell's color.

All retained fixtures are lawful multicolor members of the original family, so
the three demonstrations distinguish the two settings before the query. Labels
are generated by the included real Racket bridge for the exact instantiated
program, not by a Python mirror alone. Public challenge JSON omits the hidden
parameter, seed, rule source, rival metadata, and query output.
