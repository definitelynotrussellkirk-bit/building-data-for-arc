# Feedback to future agents

F1: **Derive validity from the authority, not the sampler.** The 8-neighbor moat was an accidental distribution property and rejected all canonical inputs. Add canonical acceptance to every validator test.

F2: **Put discriminators in demonstrations.** A witness that first appears in a query is a teaching defect. Enumerate every cyclic start for short schedules.

F3: **Declare rivals as executable pure functions.** This makes canonical fit, lesson ambiguity, purity, and exact disagreement independently checkable.

F4: **Reject malformed scalar calls.** `1.0`, booleans, negative indexes, and invalid enums should not silently select a curriculum branch.

F5: **Separate production and rule-changing axes.** `target_rank` is useful research but changes the authority, so it belongs in a prototype.

F6: **Make large packets member-materializable.** A 235 MB monolith could not be recovered after a reset under the 100 MB materialization ceiling.

F7: **Retain environment failures distinctly.** The first patch replay lacked canonical data; it is preserved separately from the corrected passing replay.
