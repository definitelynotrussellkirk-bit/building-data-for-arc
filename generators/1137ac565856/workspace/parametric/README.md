# Frame-width relay family

The exact canonical default remains unchanged. The alternate first identifies
the smallest complete frame that strictly encloses the red marker, converts its
width 3/5/7 into payload index 1/2/3, then selects the corresponding row-major
color-9 payload and repaints it cyan. Each scene also contains a smaller
non-enclosing decoy frame, so global-smallest is a concrete wrong rule.

The fourth query is a substantive 30x30 case. The protected counterfactual
skips containment and uses the globally smallest frame.
