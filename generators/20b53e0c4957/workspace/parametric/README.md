# Native parametric family

`hole_policy=preserve` is the exact canonical rule. `repair_then_transfer`
repairs the occupied C bounding box before applying the input-derived A-minus-B
removal mask. Inputs are matched across settings; all scenes contain an
independent C hole, translated A/C origins, nonempty removals, four distinct
queries, and a lawful 30x29 stress case (30 columns cannot encode three equal
panels plus two divider columns).
