# Native family: rectangle fill then cue-selected region

`fill_only` is the exact canonical authority. `cue_selected_region` first fills
both yellow-corner rectangles red, then uses the visible color-3 edge cue to
select one of the newly created red components and recolors it color 8. The first
two demonstrations reverse both row-major order and size rank, refuting
first/last/largest/smallest shortcuts without increasing the two-demo budget.
