# 7b0cb3b9a618

Layered crossing bands on a zero background. Distinct-colored horizontal and
vertical bands are painted in an acyclic order. The output is the color of the
unique uninterrupted final band: directly from a clean horizontal row, or from
the single anomalous cell in a nearly uniform row when the winner is vertical.

The generator schedules all six canonical `(height, width, palette-size)`
profiles in both winner orientations, with one exact public control:
`clean_color` in `1..9`.

Kind: `per_puzzle`. Selected version: `2.0.0`.
Approval is derived by the catalog from current code and retained evidence.
