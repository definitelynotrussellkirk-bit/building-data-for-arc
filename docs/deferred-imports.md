# Deferred experiment imports

Older inactive experiments and historical launchers stay in ARCagi2 until the
user asks for a specific import. Do not copy them into this repository merely to
complete an inventory. Maintained generator, training and model workflows remain
in their existing homes.

Archive copies had already been made before this preference arrived. Those copies
were moved out of the focused repositories into a recovery-only location; no
original source was moved or deleted. The [receipt](migration/deferred-imports.json)
records their former paths, recovery locations, manifests and original sources.
These recovery copies are not an imported experiment or a runtime dependency.
